# Original asset and screenshot guide

This relaunch uses an original **biomechanical terminal** presentation. It can be produced without a digital artist and must not recreate characters, official logos, frames, screenshots, or key art.

## Required assets

| Asset | Working size | Delivery |
|---|---:|---|
| Marketplace icon | 1024 × 1024 source | export `images/icon.png` at 256 × 256 |
| README hero | 1600 × 900 | `images/nge-terminal-hero.png` |
| Unit-00 screenshot | 1600 × 900 | `images/eva-00-demo.png` |
| Unit-01 screenshot | 1600 × 900 | `images/eva-01-demo.png` |
| Unit-02 screenshot | 1600 × 900 | `images/eva-02-demo.png` |

## Visual system

- Base: near-black graphite and deep green-black.
- Geometry: layered armor plates, neural-core rings, grids, calibration marks, and narrow signal lines.
- Accent channels: violet/acid-green, cobalt/amber, and red/orange.
- Typography in promotional layouts: condensed technical sans plus a neutral monospaced face.
- Avoid official symbols, characters, recognizable silhouettes, episode imagery, copied typography, and franchise logos.

## Screenshot recipe

1. Create a clean OS account or use a short fixture directory such as `~/nge-theme-demo`.
2. Open only the files under `demo/`.
3. Disable breadcrumbs, minimap, accounts, notifications, source-control badges, and unrelated extensions.
4. Use a neutral workspace name such as `signal-lab`.
5. Verify that the title bar, tabs, terminal, status bar, and code contain no username, home-directory path, company name, token, hostname, or private repository.
6. Capture the same code and framing for all three themes so visitors compare color systems rather than layouts.
7. Export PNG at 1600 × 900 and run a final visual scan before committing.

## Marketplace crop checks

Check the icon at 256, 128, 64, and 32 pixels. The mark should retain one clear silhouette, one luminous focal point, and no fine text.
