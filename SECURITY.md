# Security

Do not report public theme color or presentation issues as security vulnerabilities; use the normal issue tracker.

For an accidentally committed credential or other sensitive disclosure, email [engr.log@gmail.com](mailto:engr.log@gmail.com). Revoke or rotate an exposed credential immediately before attempting repository cleanup.

Marketplace publishing tokens must be supplied only through a local secure prompt or an encrypted CI secret. They must never be stored in source files, documentation, screenshots, Notion pages, shell history examples, or issue content.
